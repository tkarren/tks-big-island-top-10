# Card photos

Drop card photos in this folder and add these attributes to the matching `<article class="card">` in `index.html`:

```html
<article class="card" data-category="Beach" data-tags="All|Beaches"
  data-photo-src="assets/photos/example.jpg"
  data-photo-alt="Short alt text"
  data-photo-caption="Caption shown over the image">
```

Cards with `data-photo-src` automatically get a **Show photo / Show info** flip button.
